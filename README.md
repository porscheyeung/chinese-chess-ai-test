# 中國象棋

以 `index.html` 為目前入口；可直接用瀏覽器開啟。其他 HTML 是歷史版本，未同步改動。

## AI 與十級難度

只調整 AI 與原有難度區域，保留棋盤、雙人模式、讓棋、悔棋、翻轉、動畫與重複局面限制。

|級別|每步搜尋預算（毫秒）|最大深度（半回合）|候選容許分差|
|---|---:|---:|---:|
|1|60|1|500|
|2|100|1|320|
|3|160|2|210|
|4|250|2|130|
|5|400|3|75|
|6|650|4|40|
|7|1000|5|22|
|8|1500|6|12|
|9|2200|7|5|
|10|3200|8|0|

這些是內部等級，不代表正式段位、Elo 或每局必勝關係。深度是上限，實際視局面和裝置速度而定。第一輪先做基本搜尋，後續加入吃子延伸；限時未完成的輪次不覆蓋完整結果。極慢裝置至少有合法的靜態評分備選。時間預算不含初始化、候選生成及動畫，並非嚴格的整步時間上限。

搜尋使用迭代加深、Alpha-beta 剪枝、走法排序與置換走法提示；不再直接刪除排序較後的合法走法。靜態延伸遇將軍必須搜尋應將；無棋可走判負。搜尋內重複路徑以和局分處理，實際落子仍沿用現有第三次重複禁止規則。置換表只作排序，避免將剪枝邊界誤當精確分數。

低級容許較大的選棋誤差，高級逐步收窄；10 級選擇已完成搜尋的最高分。開局庫必須通過合法性及當前搜尋分數檢查，不強制照譜落子。Web Worker 在背景搜尋；不支援 Worker 時使用同步備援。

## 典籍參考與界線

- 《橘中秘》：出車、爭先與子力活動，轉為車馬開發及活動空間評分。
- 《梅花譜》：屏風馬對中炮的協調思路，保留多種開局候選並經搜尋覆核。
- 《適情雅趣》的《棋經論》與殺法研究：轉為重視將帥安全、應將及戰術延伸。
- 殘局評分另以工程啟發式調整馬炮相對價值、過河兵與連兵，降低沉底兵價值。

這是受棋理啟發的人工評分，沒有訓練模型、完整匯入典籍棋譜或實現殘局資料庫；六條短開局變化為專案原有內容修正，並非逐手抄錄古譜。

## 驗證

執行 `node tests/ai.test.cjs`：初始合法走法、評分對稱、開局庫每步合法性、應將、困斃、十級設定、出棋合法性、棋盤不被搜尋修改及基本時間界限。

未進行大規模自我對弈排名；不能保證相鄰等級在每局都有可測量的棋力差距。
